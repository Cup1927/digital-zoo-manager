
# Digital Zoo Manager

A Java desktop application for managing animals in a digital zoo.

## Features
- Add mammals and birds
- Enter animal name and age
- Set fur color for mammals
- Set flying ability for birds
- Display animal information and sounds
- Store animals using ArrayList

## Technologies
- Java
- Java Swing
- IntelliJ IDEA

## OOP Concepts
- Encapsulation
- Inheritance
- Method Overriding
- Polymorphism

## Project Structure
- Animal.java - Superclass
- Mammal.java - Mammal subclass
- Bird.java - Bird subclass
- ZooFrame.java - GUI and application logic
- Main.java - Application entry point

## How to Run
1. Open the project in IntelliJ IDEA.
2. Make sure JDK is configured.
3. Open Main.java.
4. Run Main.main().
5. Use the form to add animals.

## Data Storage
Animal data is stored temporarily in memory using ArrayList.
